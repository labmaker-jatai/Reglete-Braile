# Reglete para Escrita em Braille

## Descrição do projeto

Este projeto apresenta uma **reglete para escrita em Braille**, produzida em MDF e desenvolvida para a confecção de materiais didáticos acessíveis. Com dimensões de **380 mm × 580 mm**, o dispositivo permite a escrita por meio de pinos impressos em 3D, cujas extremidades utilizam esferas de rolamento para proporcionar maior conforto durante a exploração tátil.

A reglete possui **17 linhas, com 21 celas Braille por linha**, totalizando 357 celas para a composição de textos e atividades pedagógicas.

O projeto combina fabricação digital, corte a laser e impressão 3D, oferecendo uma alternativa para a produção de recursos de tecnologia assistiva voltados à educação inclusiva.

## Materiais e processos de fabricação

- **Estrutura:** MDF, cortado a laser.
- **Pinos:** peças produzidas por impressão 3D.
- **Extremidades dos pinos:** esferas de rolamento para favorecer o contato tátil.
- **Softwares:** LibreCAD, Inkscape, AutoLaser e software de fatiamento para impressão 3D.

## Aplicações educacionais

A reglete pode ser utilizada na produção de atividades de escrita e aprendizagem do sistema Braille, contribuindo para o desenvolvimento de recursos didáticos acessíveis e para a ampliação das possibilidades de participação de estudantes com deficiência visual.

O projeto também pode servir como referência para laboratórios maker, instituições de ensino e educadores interessados em desenvolver e adaptar tecnologias assistivas por meio da fabricação digital.
